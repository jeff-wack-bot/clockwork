⚙ Clockwork Board — style lab

Every tile is the live board, zoomed into the Phasor inside the VCO (the oscillator's ramp: multiply, add, compare, subtract, switch, flip-flop). The chosen default is special vias, no branch marks, taper, plain registers; each row varies one of these and keeps the rest. The clock runs slowly (300 ticks/s), so you can see values move.
